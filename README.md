## 🛠️ How Does It Work? (Simple Explanation)

context-mode uses two standard technologies:

- **MCP (Model Context Protocol)** – a common language that lets AI tools share context. Think of it as a universal power plug for AI.
- **Hooks** – small triggers that run automatically when certain events happen (like a tool finishing its job). context-mode uses these to clean up and save data in real time.

You don't need to understand the technical side. Just know that these are industry-standard methods used by major AI companies.
